# Отчёты Allure для UI

Финальные прогоны 18.11.2026. Проверена версия с классами тестов и отдельным пакетом локаторов.

- [Chrome — 9 passed](allure-chrome.zip).
- [Firefox — 9 passed](allure-firefox.zip).

Скачайте и распакуйте нужный архив. Из папки с распакованным отчётом выполните одну команду:

```bash
allure open allure-chrome
allure open allure-firefox
```

Для просмотра необходим Allure CLI.
